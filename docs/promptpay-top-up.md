# เติมเหรียญด้วย PromptPay

ใช้ QR รับเงินแบบไม่ล็อกยอดจากแอปธนาคารของบัญชีที่จะรับเงิน ตรวจชื่อผู้รับและทดสอบสแกนในแอปธนาคารก่อนเปิดให้ผู้เล่นใช้ เก็บเฉพาะภาพ QR ที่จะให้ผู้เล่นเห็นไว้ใน `public/payment/` ควรเปิดบริการเมื่อมีคนตรวจยอดธนาคารและดูแลรายการที่ลูกค้าแจ้งผิดได้

## ค่าตั้งบน Vercel

| ตัวแปร | ค่า |
| --- | --- |
| `NEXT_PUBLIC_MORRIS_TOPUP_ENABLED` | `true` เพื่อแสดงปุ่มเติมเหรียญในร้านหลัง deploy |
| `MORRIS_TOPUP_ACCEPTING` | `true` เพื่อเปิดรับแจ้งโอนเมื่อยืนยัน QR แล้ว |
| `MORRIS_TOPUP_ADMIN_PLAYER_ID` | ไอดีเกมของผู้ตรวจยอด ใช้ค้นหาเจ้าของบัญชีฝั่งเซิร์ฟเวอร์ |
| `MORRIS_TOPUP_QR_PATH` | ที่อยู่ภาพในเว็บ เช่น `/payment/promptpay.png` |
| `MORRIS_TOPUP_RECIPIENT` | ชื่อผู้รับที่แอปธนาคารแสดงตอนสแกน |

ใช้ `NEXT_PUBLIC_MORRIS_TOPUP_PREVIEW=true` แยกต่างหากหากต้องการดูหน้าแพ็กโดยยังไม่เปิดรับชำระ ค่า `MORRIS_TOPUP_ACCEPTING` ที่ไม่ได้ตั้งจะปิดรับแจ้งโอน แม้เปิดให้เห็นปุ่มแล้ว

## ตรวจยอด

ผู้เล่นเลือกแพ็ก สแกน QR ด้วยแอปธนาคาร และแจ้งชื่อผู้โอนกับเลขอ้างอิงจากรายการจ่าย ผู้ตรวจเปิด **ร้านค้า → เติมเหรียญ → ตรวจรายการโอน** เทียบชื่อผู้โอน เลขอ้างอิง ยอด และเวลาจากรายการเงินเข้าจริงของธนาคาร แล้วจึงอนุมัติ เลขอ้างอิงที่อนุมัติแล้วเติมเหรียญซ้ำไม่ได้ ผู้เล่นกด **อัปเดตสถานะ** เพื่อตรวจรายการและยอดเหรียญ

เมื่อต้องหยุดรับรายการ ให้ตั้ง `MORRIS_TOPUP_ACCEPTING=false` แล้ว deploy โดยคงทางเข้าผู้ตรวจไว้เพื่อตรวจรายการเดิม
